# hoeger.dev — Gestaltungsvorschau

Separate statische Vorschau des Website-Neubaus, Stand November 2026. Dieser Showcase ersetzt die Produktivwebsite nicht.

- Kinevato-Gestaltung, interaktive Smartphone- und Automationsdemo.
- Beispieldaten; Kontaktformular und Tracking im Showcase deaktiviert.
- Rückmeldungen werden vor einer gesondert freigegebenen Veröffentlichung auf hoeger.dev eingearbeitet.

Die Vorschau enthält einen statischen Export. Die bearbeitbare Projektquelle wird getrennt verwaltet.
